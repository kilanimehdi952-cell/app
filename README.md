# 🧠 منصة المساعد الذكي الشاملة

مرحباً بك في المستودع البرمجي الخاص بـ **منصة المساعد الذكي الشاملة** المخصصة للهواتف والويب.

## 🚀 خدمات المنصة الحالية:
1. **💼 قسم كاتب الإعلانات للتجار:** أداة ذكية لتوليد منشورات تسويقية واحترافية لأصحاب المحلات والسلع مع ميزة النشر التلقائي المباشر على فيسبوك.
2. **🎓 قسم المساعد التعليمي للطلاب:** واجهة مدمجة ومباشرة لربط الطلاب بـ **خادم الذكاء الاصطناعي على ميسنجر** لحل التمارين وتلخيص الدروس.

## 🛠️ التقنيات المستخدمة:
* لغة البرمجة: **Python**
* المكتبة الرسومية: **Streamlit**
* منصات الربط: **Facebook & Messenger API
